# Хронбург — дело о пропавшем Новом годе 🎄

Интерактивный математический адвент-квест: одна история для **ОГЭ** и **ЕГЭ (профиль)**, с раздельными задачами и прогрессом.

## Прототип 0.3

- Главная карта из `assets/maps/chronburg_map_base.png`
- Календарь на 24 дня (пока реализован только день 1)
- Переключение ОГЭ/ЕГЭ профиль
- День 1: «Огонёк надежды», по 4 проверенных математических задания в каждом режиме: 3 контура + завершающий замок Искры времени
- Интерактивный распределительный щит поверх локации, три независимые секции освещения, смена настоящих изображений по мере ремонта
- Задания в модальном окне, математические подсказки и решения в KaTeX
- Сюжетные реплики Тика по мере восстановления света, сцена вручения фонарика
- Необязательные звуковые сигналы (изначально отключены), адаптивная мобильная раскладка
- Резервные аналоги для всех четырёх заданий первого дня (по кнопке после ошибки), подсказки, поле для ответа, математическая клавиатура, черновик для стилуса и мыши
- Первая искра, игрушка-фонарик, простая ёлка и локальное сохранение прогресса
- Экспорт/импорт сохранения в JSON
- КаTeX для формул

## Как открыть

После настройки GitHub Pages: https://marianikitina0603-del.github.io/advent/

До 1 декабря тестируйте: https://marianikitina0603-del.github.io/advent/?preview=1

Для прямого выбора экзамена добавьте `&exam=oge` либо `&exam=ege` к ссылке предпросмотра.

Настройка: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Важно

- `preview=1` — **только проверка интерфейса**. Это не защита паролем и не система учительских прав.
- В общедоступном репозитории сейчас размещены ответы на тренировочные задачи первого дня в JavaScript. Для секретных будущих заданий понадобится отдельное приватное хранилище и публикация по расписанию.
- На 2–24 декабря нарисована карта и календарь, но сами игровые испытания **ещё не реализованы**.
- Ограничение по дате сейчас клиентское, для защищённого запуска потребуется настроить GitHub Actions и не публиковать содержимое будущих дней.
- 3D-ёлка пока заменена плоским макетом с наградой; настоящую вращаемую модель GLB/Three.js добавим отдельно.
- Состояния освещения теперь подгружаются из assets/locations/day01_street_lanterns_state1.webp, state2.webp, state3.webp с плавным переходом. В качестве состояния 0 используется оригинальный day01_street_lanterns.png, поскольку state0.webp пока отсутствует.
- Экспорт сохраняет только выбранный режим. Прогресс хранится в localStorage браузера.

## Источники заданий и приватность

Задания первого дня перенесены из приложенных пользователем DOCX (основные и резервы ОГЭ / ЕГЭ) в `data/day01.js`. Ответы пересчитаны отдельно. Основные задания имеют общую расчётную длительность 13 минут. Три первых задания включают три контура, четвёртое открывает финальную награду.

Полный комплект на 24 дня **не коммитился**: публичный GitHub Pages не подходит для хранения будущих заданий, скрытых только JavaScript. Данные будущих дней хранятся в отдельном приватном архиве до настройки отложенной публикации.
