ХРОНБУРГ — ОГЭ. ИЗОБРАЖЕНИЯ К РЕЗЕРВНЫМ ЗАДАНИЯМ
Формат имён: oge_r_ДД_ЗЗ.png, где ДД — номер дня (01–24), ЗЗ — порядковый номер резервной задачи внутри этого дня.
Включены рисунки, планы, координатные прямые, графики и диаграммы.
Изображения извлечены из файла «Открытый банк заданий ФИПИ.pdf» либо из ранее подготовленного документа резервов.
Включены только задания, которым нужны изображения. Текстовые и табличные задания без рисунка здесь отсутствуют.
Точное соответствие ID и страниц — в файле «Индекс_изображений.csv».
Одна картинка соответствует одному заданию, включая набор из нескольких графиков внутри рисунка.
