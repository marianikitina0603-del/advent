## Объём и ограничения проверки

Проверены актуальные HTML/CSS/JavaScript и структура ассетов GitHub. Проведена статическая проверка синтаксиса скриптов, соответствия `id` страницы и обращений JS, наличия картинок, дат релиза, связей страниц, банков математических заданий (структура приватных комплектов 2–7), а также моделирование загрузки страниц 4–7 и действий для дней 6–7.

**Не выполнены:** полноценный браузерный/пиксельный визуальный аудит всех семи опубликованных страниц (внешний GitHub Pages из текущей среды недоступен), проверка реальных задержек мобильной сети, фактическое состояние GitHub Actions после последнего коммита, тест на реальном планшете. Поэтому нельзя заявлять, что все визуальные наложения и движения проверены на устройстве.

## Исправления этого аудита

1. **День 3:** основной рисунок первого задания ОГЭ переподключён на `assets/pic/oge_osn/oge_03_01.png`. Ошибка была в исходном пути в одном из закрытых комплектов; защищённый банк не раскрывался и не изменялся, исправление выполнено в рендерере только для основного задания.
2. **Календарь:** только явный `preview=1` включает учительский предпросмотр; `preview=0` больше не снимает календарную блокировку.
3. **Загрузка закрытых банков:** клиент релизов теперь подтверждает готовность лишь после успешной валидации страницей. Дни 4–7 корректно отклоняют ошибочный формат вместо ложного сообщения об успехе.
4. **GitHub Actions:** тест дат публикации умеет различать уже опубликованные дни и будущие дни. После 2 декабря он не должен падать только из-за существования законно опубликованных JSON; преждевременная публикация по-прежнему считается ошибкой.
5. **Регрессионные тесты:** добавлен `scripts/check_chronburg_static.py` и автоматический job `static-scenes`, запускающий проверки структуры на изменениях HTML, JS, CSS и ассетов.

Дешифрование зашифрованного комплекта дня 7 отдельно проверено локально с его ключом; публикация остаётся датированной 7 декабря 2026 года. В открытом JS будущие ответы отсутствуют.

Эти проверки **не заменяют** самостоятельного решения каждой задачи и сверки всех рисунков в браузере.
