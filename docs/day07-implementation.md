# День 7. «Волна праздничного света» — реализация

Дата открытия математических заданий: **7 декабря 2026 года, Europe/Moscow**.

## Сцена и анимация

- Игровая страница `day07.html`, CSS `css/day7-lights.css`, JS `js/day7-lights.js`.
- Основной фон: `assets/locations/day07_square_unlit.webp` (16:9).
- Праздничные частицы: `assets/locations/day07_magic_glow.webp` (16:9).
- Награда: `assets/ornaments/ornament_day07_garland.webp`.
- SVG-слой с viewBox `1920 1080`; провода и лампочки — отдельные элементы, анимация запускается через `requestAnimationFrame`.
- Маршруты: левая гирлянда, правая гирлянда, огни часовой башни, верхняя праздничная дуга.
- Лампочки загораются **по мере прохождения импульса** и остаются включёнными.
- Ошибка вызывает короткое мигание на текущем участке, без отката пройденных участков.
- В ОГЭ 3 задачи, после третьей автоматически проигрывается четвёртая финальная дуга; в ЕГЭ 4 задачи, последняя запускает дугу.
- Сцену и координаты траекторий необходимо проверить по реальному фону на компьютере и планшете. Координаты в JS допускают последующую точную калибровку по скриншоту.

## Математические задания

- Использованы задания дня 7 из подготовленных DOCX/JSON основного и резервного комплектов ОГЭ/ЕГЭ.
- ОГЭ: №7 (координатная прямая), №8 (степени), №11 (квадратичные функции).
- ЕГЭ профиль: №7 (степени), №9 (закон Ома, движение с ускорением, лебёдка).
- Четыре иллюстрации для ОГЭ: `assets/pic/oge_osn/oge_07_01.png`, `assets/pic/oge_osn/oge_07_03.png`, `assets/pic/oge_reserve/oge_r_07_01.png`, `assets/pic/oge_reserve/oge_r_07_03.png`.
- Формулы и ответы проверены по исходным заданиям; графики и координатная прямая отдельно сверены визуально с PDF. Отличие библиографических меток в подготовленном DOCX: задание с корнем из 28 соответствует аналогу 7.17.1 в PDF, а с корнем из 33 — аналогу 7.17.2; номер в метаданных исходной подборки не считается самостоятельным ключом проверки.
- Тексты, числовые ключи и резервы **не публикуются** до даты открытия.

## Безопасность

- В публичном репозитории только зашифрованный `data/locked/day07-2026.enc.json` (AES-256-GCM и zlib, формат релизного скрипта).
- Действующий `scripts/release_chronburg.py` выпускает `data/day07.json` по расписанию, если настроен секрет `CHRONBURG_RELEASE_KEY` и GitHub Actions выполнен успешно.
- `js/chronburg-release-client.js` опрашивает опубликованный файл, не содержит секретного ключа или преждевременно раскрытых ответов.
- `?exam=oge&preview=1` — демонстрация анимаций без записи результата; локальная загрузка закрытого учительского JSON позволяет пройти настоящие задачи без публикации файла в репозитории.
- Локальное сохранение: `chronburg:2026:day07:oge:v1` и `chronburg:2026:day07:ege:v1`. При переключении экзамена прогресс не смешивается.
