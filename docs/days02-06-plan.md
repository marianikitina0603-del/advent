## Проверка перед программированием

- Исходный текст, таблицы и математические формулы должны быть сохранены точно, без потерь при импорте DOCX.
- ОГЭ, день 2: две таблицы должны сопровождать практические задачи (они не помещаются в одно текстовое поле).
- ОГЭ, дни 3 и 5: проверить 4 основных и 4 резервных задания по рисункам, прежде чем включать автопроверку.
- ЕГЭ, день 5: убедиться, что три основных и три резервных рисунка геометрии соответствуют тексту.
- Не перегружать день резервами: для завершения за 20 минут показывать аналог только для затруднившего задания.
- Не публиковать условия будущих дат в клиентском JavaScript, скрывая их только датой или CSS: содержимое публичного репозитория доступно всем.

## Игровой шаблон

Использовать текущий принцип первого дня: локация на весь доступный экран, задание открывается **только нажатием**, после верного ответа модальное окно закрывается, сцена меняет состояние, результат сохраняется отдельно для ОГЭ и ЕГЭ. Для каждой локации смена состояния должна соответствовать её сюжету. Подсказки пока оставляем в текущем формате, без уровней.

Условия, ответы и резервы будущих дней зашифрованы в `data/locked/`; для дня 6 создан отдельный `day06-2026.enc.json` с датой выпуска 6 декабря. В публичный JS закрытые задачи не встроены.
